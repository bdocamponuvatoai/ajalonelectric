# Verification — Next.js migration parity

Measured on 29 October 2026, comparing the original ChatGPT-built static site
(`dist/`, generated by `build.py`) with the Next.js static export (`out/`).
Both were served locally by the same small Node static server (directory
index files, `404.html` fallback) and driven with Playwright 1.64 against the
system Google Chrome (no bundled browser).

## Capture setup

- Viewport widths 1600, 1280, 1024, 768, 390 and 320 px; device scale factor 1;
  `prefers-reduced-motion: reduce`.
- Before each capture: lazy images switched to eager and `img.decode()`
  awaited, every `FontFace` loaded and `document.fonts.ready` awaited, network
  idle, then a full-page screenshot repeated until two consecutive frames were
  byte-identical.
- Chrome ran with CPU raster (`--disable-gpu`), no checker-imaging, no partial
  raster and one raster thread. With GPU raster, downscaled photos were
  filtered differently from run to run: the _original_ site differed from
  itself by up to 85,731 pixels between two captures. CPU raster removed that.
- `<select>` elements are re-laid out once after fonts load. Without this the
  original site kept the pre-font-swap paint of the "Property type" select at
  320 px (a forced relayout changed the original by exactly the 137 pixels
  that differed and made it identical to the new build).

### After cleanup (Phase 5)

The owner-approved removal of the footer preview note ("Private design
preview. Branding and photographs are proposed concepts; …") was re-verified
by hiding `.preview-note` on the original site and repeating every check:

- Full-page pixel diff: **0 differing pixels in all 78 pairs**.
- Open-state screenshots: **0 differing pixels in all 13**.
- Behaviour scenarios: **7 of 7 identical**.
- Navigation: 0 unexpected 4xx (334 prefetch requests), 0 console errors.
- The DOM diff differs only by the removed paragraph.

So the note is the only change. Pages are 41 px shorter at 1280 px, 90 px at
390 px and 106 px at 320 px. No spacing needed moving: the note did not clear
the fixed mobile bar (the body's 70 px bottom padding does that, and the bar is
about 65 px tall). The footer keeps its own 30 px bottom padding.

`npm audit --omit=dev`: 0 vulnerabilities (`npm audit` including dev
dependencies: also 0).

## Differences found and fixed during verification

- **"←" glyph:** next/font's default `adjustFontFallback` inserts a
  size-adjusted Arial face before the real fallbacks, so glyphs Inter lacks
  rendered differently. Disabled for both fonts.
- **Hero gradient:** the build's CSS minifier rewrote
  `linear-gradient(0deg, …)` into the reversed `linear-gradient(#0000 65%, …)`,
  which Chrome rasterizes ±1 per channel differently. Written as `360deg`,
  which the minifier keeps as is.
- **CSS cascade:** splitting the stylesheet into partials would have changed
  `.split-copy` / `.generator-tool` bottom padding between 741 and 1200 px,
  where the original `.section` media rule won by source order. The effective
  values are stated explicitly in `pages/service-detail.css`. Every other rule
  pair whose order changed was checked in the browser against all original
  pages and states: none match the same element with a conflicting property.
- **Focus after navigation:** client-side navigation left focus on the clicked
  link. Focus now returns to the top of the document, so the next Tab reaches
  "Skip to content" as it did after a full page load.

## Remaining, intentional differences

- **DOM:** IDs used only by the old script were dropped (`priority-count`,
  `live-summary`, `email-brief`, `download-brief`, `download-status`,
  `form-error`, `previous`, `data-*` hooks); buttons gained `type="button"`;
  React renders `value=""` on empty inputs and omits empty `class=""`;
  whitespace-only text nodes between the planner fieldsets are gone.
- **Keyboard:** the project-guide options additionally respond to arrow keys,
  Home and End. Tab, Enter and Space behave as before.
- **Head:** the new pages add `og:url`, Open Graph image dimensions, Twitter
  card tags, preloads for both fonts (the original preloaded Manrope only) and
  LocalBusiness JSON-LD on the home page. The favicon is served from
  `/icon.svg`. The canonical origin comes from `SITE_URL` instead of the old
  preview domain. The 404 page has no canonical or Open Graph tags and Next
  adds `noindex`.
- **Fonts:** the four literal family lists were replaced by two tokens,
  `--font-sans` (Inter, Arial, sans-serif) and `--font-display` (Manrope,
  Arial, sans-serif). Where the original listed `Manrope, sans-serif` or
  `Inter, sans-serif`, Arial is now listed too. That only matters if the
  bundled fonts fail to load.

## Not covered

Real iOS and Android devices, Safari and Firefox were not tested. Mobile
widths were checked in Chrome's desktop engine only.
